## 音の分析（ゴッドイーター）
- 勝利音：太い低音のうなり（約5秒）→ 細かい連打 → **約1秒の無音** → 2〜5kHzの澄んだ高音（倍音が縦に並ぶ電子音）
- フリーズ音：ブザーのような和音 → **約5秒の完全な無音** → 音が戻る。字幕「引けるのか？のプレッシャーから一気に解放される」
- 神告知：細く高い音が鳴り続ける → ドカンと全帯域の一撃＋音程が滑る音 → キラキラした和音が長く響いて消える
- 字幕「前半の低音が体に響く／後半の突き刺すような高音」

## 脳汁演出の型
1. **溜め（無音・暗転）**：1〜5秒。長いほど期待が上がる。画面全部ではなく液晶だけ消す手もある
2. **小出し**：文字や数字を1文字ずつ・一部ずつ、超アップで見せる。全体はまだ見せない
3. **反転・閃光**：補色（青）や白のフラッシュを一瞬はさむ
4. **ドン（全体登場）**：金属・金・虹の極太文字が中央に収まる。稲妻・放射線・炎・破片
5. **色の格上げ**：青 → 赤 → 金 → 虹。白（無色）から虹に塗り替わる「昇格」も強い
6. **積み上げ**：数字の上乗せ、ボタンや仕掛けの色の段階アップ
7. **音**：低音で体に響かせる → 無音 → 突き刺す高音 → 長い余韻
8. **枠ごと光る**：画面の外側（台の枠）の光の色が次々変わる

## 文字の見た目（2回目の調査。試作1号は「0点」＝ここが致命的に足りなかった）

参考動画の文字を 1080p で拡大して確認した。

### 「確定」（mWqWfEkaHR4）
- 書体：極太で、線の端が**斜めにスパッと切れた**角ばった形（丸みがない）
- 表の面：グラデーションではなく、**上半分が明るい金・下半分が暗い焦げ茶**の2色に、**水平線でパキッと割れる**（金属に映った「空と地面」）
- 縁：外へ向かって「細い黒線 → 細い明るい金線 → 黒線 → 太い金の縁（これも2色に割れる） → 黒 → 奥へ伸びる厚い側面」の**何重もの段**
- 側面：奥行きは文字の高さの 1/4 ほど。**面ごとに明るさが違う**（光が当たる面は明るい金、反対側は暗い紺）＝カクカク
- 少し下から見上げる角度。床に映り込みがある

### 「FEVER」「6223800708」（1ZmNP3vFBz4）
- 1文字ずつ別々の立体として飛んでくる。**宝石のように三角の面で刻まれた**赤い本体＋銀の文字＋金の縁
- 数字は縦長で角を斜めに落とした八角形っぽい書体。虹の面にザラザラした光の粒、黒い縁、奥に深い金の側面

### 「緊急事態」（fMD9R7CIung）
- 縁がギザギザに欠けた筆系の書体。赤い金属で、くぼみが黒く、縁が光る

### 業界での作り方（[パチンコパチスロ開発.com](http://xn--tckmwb1fc2rrbx534jj6sc.com/pachinko/)、[Edit](https://edit-films.com/pachinko-letter-element-3d/)、[megabenri](https://megabenri.com/blog/pachinko-font-guide/)）
- 金文字：**白黒の濃淡＋ベベル → トーンカーブ（色の対応表）で金色にする**。対応表を波打たせると明暗の帯が何本も出て「ギラギラ」になる
- 3D なら：押し出し＋面取り → 反射の強い金属の材質 → グロー（光のにじみ）
- 縁は多層：中心（金属）→ 黒 → 白い光 → 赤か金の極太フチ → グロー。内フチと外フチの太さはおよそ 1:2
- 色の組み合わせ：虹＝7色×白フチ×金フチ／金＝金×黒フチ×赤フチ
- 右へ 10〜15 度傾けると勢いが出る

### 先行例：パチ文字メーカー（[note](https://note.com/hiroga/n/ne2f97cc6ec2b)、AGPL のためコードは使わない）
- three.js で文字を押し出し＋面取りして 3D にしている。書体は Noto Sans／装甲明朝／玉ねぎ楷書「激」
- 面取りの縁が平らな面の組み合わせになり、面ごとに明るさが変わる → これが「カクカク」の正体
- ただし映り込み・光のにじみはなく、まだ平たく見える

### 書体の候補
- **装甲明朝**：角ばった極太明朝。SIL OFL 1.1（アプリに入れて無料で使える）。第一候補
- そのほか OFL：源界明朝（欠けた明朝。緊急事態系）、Noto Serif JP Black、数字用に縦長の英字書体
