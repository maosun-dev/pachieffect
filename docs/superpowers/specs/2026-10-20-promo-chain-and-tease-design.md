# 昇格の色を7段から選ぶ・チラ見せの色と文字数 仕様書

2026-10-20 作成。ユーザーとの相談で決めたこと。前の仕様書（2026-10-18-app-release-design.md）の「昇格の範囲」と、昨日足した「最初の文字色・最初の背景」（ドンの着地から金に変わるまでの色）を置き換える。

## 狙い

- パチンコの色の格どおりに昇格させたい：**銀 → 青 → 緑 → 紫 → 赤 → 金 → 虹**（今の設定は紫と赤が逆になっていた）
- 昇格で通る色を好きに選びたい（例：緑 → 赤 → 虹）
- 凱旋GODのように文字を1文字ずつ嘗め回して見せる「チラ見せ」の、文字の色と背景の色を選びたい
- チラ見せの文字数を選びたい（今は最大4文字。全部も見せたい）
- 演出が長くなってもかまわない（ユーザー）

## 色の格

| 格 | 文字 | 背景 |
|---|---|---|
| 銀 | 今の銀 | 灰色・白の熱くない暗がり（青ではない） |
| 青 | 銀の明るさの並びに青を乗せる | 青（今の青の背景） |
| 緑 | 同じく緑 | 緑（青の背景の色相を回す） |
| 紫 | 同じく紫 | 紫 |
| 赤 | 同じく赤 | 赤 |
| 金 | 今の金 | 炎（今の金の背景） |
| 虹 | 今の虹 | 虹（今の虹の背景。ときどき青・炎に切り替わり、最後の 0.4 秒は虹） |

- 文字の色の芯は、昨日作った `FirstColors.TextBase` の値（青 `#2A7BFF`・緑 `#19D14A`・紫 `#A040FF`・赤 `#FF2030`）、背景の色相の回しも昨日の値（緑 -85°・紫 65°・赤 125°）を使う

## 演出の流れ

1. プチュン → 暗転（今のまま）
2. **チラ見せ**：言葉の頭から、設定の文字数ぶん1文字ずつ見せる（0＝なし〜12。言葉の文字数より多ければ全部）
   - 1文字ごとにカメラの動きを変えて回り込み、あいだに暗転（今のまま）
   - だんだん速く：1文字の長さ 0.9 → 0.75 → 0.6 → 0.55 → …最短 0.45 秒、あいだの暗転 0.5 → 0.4 → 0.3 → …最短 0.2 秒。12文字で約8秒
   - 文字は「チラ見せの文字色」、背景は「チラ見せの背景」（どちらも7色。背景は今と同じく暗がりで、文字のうしろだけほんのり光る。銀は灰色、金は炎、虹は虹色の暗がり）
   - 0（なし）のときは、暗転からすぐ光の放射 → 白の閃光 → ドン
3. 光の放射 → 白の閃光（今のまま）
4. **ドン**：「昇格の色」の最初の色で着地。背景はその色の背景
5. **途中の昇格**（最後が虹でない段、虹の手前の段まで）：今の銀→金と同じ見せ方（前ぶれで暗く震える → 白く飛ぶ → 一瞬で次の色 → 跳ねる＋閃光）
   - 1段目は今と同じ間（ドンが動き出してから 1.3 秒で白飛び、次の段まで 1.7 秒）。段が進むごとに少しずつ詰める（白飛びまでの間・次の段までの間を、1段ごとに 0.85 倍、最短 0.7 秒）
6. **虹への昇格**：最後の色が虹で、虹の手前に別の色があるとき、今の特別な形（紫の光線で切り裂き → 灰色でタメ → 一気に虹 → 1回転・止まる・1回転）
   - 虹だけを選んだとき（虹で着地）は、今と同じく着地のあとに回転
7. 余韻（今のまま 1.8 秒）。最後の 0.4 秒は、最後の色の背景に固定する

長さの目安：「銀 → 金 → 虹」で4文字なら今とほぼ同じ（約16秒）。7色すべて・12文字で約30秒。

## 設定画面

上から：火花 → プチュンの光の色 → プチュンの光の大きさ → 書体 → **昇格の色** → **チラ見せの文字数** → **チラ見せの文字色** → **チラ見せの背景** → 買い物

- **昇格の色**：7枚の小さなメダル（銀・青・緑・紫・赤・金・虹）を格の順に1列。押すと点く・消える。点いたメダルどうしを金の帯でつなぎ、下に「緑 → 赤 → 虹」と文字でも出す。最後の1枚は消せない。既定は「銀 → 金 → 虹」。青・緑・紫・赤のメダルは今の銀・金のメダルと同じ金属の質感
- **チラ見せの文字数**：左右の矢印（◀ ▶）で 0〜12。0 は「なし」と出す。既定 12。言葉より多いときは「全部」とも分かるように、数の下に「（全部）」と出す
- **チラ見せの文字色・背景**：7つの小さな板を1列。色の名前の字をその色で書く（銀は銀、金は金、虹は虹色）。選んでいるものは今と同じ金の下線。既定は文字が銀、背景が青（今の見た目と同じ）
- 昨日足した「最初の文字色」「最初の背景」は無くす

## 保存

- 「昇格の色」は7色の組み合わせ（入っている色の印）、「チラ見せの文字数」「チラ見せの文字色」「チラ見せの背景」は数で、端末（PlayerPrefs）に残す
- 今の「はじまり・おわり」（銀・金・虹の3段）で保存している人は、同じ意味の組み合わせに読み替える（例：銀→虹 → 銀・金・虹、金だけ → 金）
- 保存が壊れていたら既定に戻す。昇格の色が空なら既定

## 確かめ方

- 自動テスト（EditMode）
  - 昇格の時刻の並び：段が何段でも時刻が前後しない／虹の特別な形が最後に来る／虹だけなら着地のあと回転／段が進むほど間が詰まり、最短を下回らない
  - チラ見せの並び：0〜12文字、だんだん速くなり最短を下回らない、言葉より多い数は言葉の文字数まで
  - 設定の保存と読み込み、古い「はじまり・おわり」の読み替え、壊れた値は既定
  - 昇格の色のメダルを押したときの組み合わせ（最後の1枚は消せない）
- 目で見る：色の組み合わせごとの絵と短い動画（movie.sh）、設定画面の絵（app-check）
- iPhone：TestFlight で見てもらう

## 入れないもの

- 段ごとに違う昇格の見せ方（赤は炎が走る、など）。今回はどの段も銀→金と同じ見せ方
- チラ見せで見せる文字を選ぶこと（言葉の頭から順）
