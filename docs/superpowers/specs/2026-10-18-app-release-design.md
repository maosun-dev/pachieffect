# 脳汁メーカー アプリ化（第1弾）仕様書

2026-10-18 作成。演出（プチュン→暗転→チラ見せ→光の放射→白の閃光→銀の文字がドン→金→紫の切り裂き→灰色のタメ→虹で回転）は完成済み（0fb0604）。この演出を第1弾として iPhone アプリにする。

## 狙い

- 使う人：パチンコ好き。自分の言葉（名前・口ぐせ・ネタ）を激アツ演出にして、友だちや SNS で笑いを取る
- いちばん大事なこと：**動画で書き出して共有できる**こと
- 収入：広告（バナー・書き出し前のごほうび広告）と、印・広告を消す買い切り。追加の演出の課金は、2つ目の演出ができたときに入れる
- 決まり：**お金をかけずに作る**（有料の部品・有料の組み立てサービスは使わない）

## アプリの名前

| 場所 | 名前 |
|---|---|
| App Store | 脳汁メーカー - パチンコ激アツ文字演出 |
| ホーム画面・動画の印 | 脳汁メーカー |
| 識別名（Bundle ID） | `com.maosundev.noujiru` |

## 第1弾に入れるもの・入れないもの

入れる：入力→再生、設定、動画の書き出し（写真に保存・共有）、バナー広告、ごほうび広告、課金3つ、購入の復元

入れない：音（第1弾は無音。音を足せる作りだけ用意し、後の版で録音素材の効果音を足す）、演出を選ぶ画面（演出が1つなので不要。2つ目が来たら足す）、新しい書体・新しい演出、ネットから演出を取りに行く仕組み

## 1. 画面と流れ

### 見た目の方針

パチンコ台そのものを手のひらに置く。いちばん目立たせるのは**巨大な赤い「PUSH」ボタン**（台のチャンスボタン）。それ以外は黒と銀でおとなしくまとめ、主役を演出とボタンに譲る。

| 役目 | 色 |
|---|---|
| 背景（演出の背景と同じ本物の黒） | `#000000` |
| 台枠のクロム銀（枠・入力欄・文字ボタン） | `#C8CDD4` |
| チャンスボタンの赤（PUSH だけ） | `#E3001B` |
| 演出の金（オンの印・買ったものだけ） | `#F2C14E` |
| 説明文の灰 | `#8A8F98` |

- 書体：見出し・ボタンは演出と同じ **Reggae One**、説明文は **BIZ UDPゴシック**（どちらも OFL で無料）
- 入力欄は、液晶の下にある銀メッキの枠のような細長い板
- 画面の部品は uGUI ＋ TextMeshPro（Unity に入っている無料のもの）で作る

### メイン画面（1画面だけ）

```
┌───────────────────┐
│                歯車│ ← 設定
│   （演出の舞台）    │ ← 入力した言葉が銀の立体で
│     退 社          │    ゆっくり揺れて待っている
│ ┏━━━━━━━━━━━━━┓ │
│ ┃ 言葉を入れる    ┃ │ ← 銀枠の入力欄
│ ┗━━━━━━━━━━━━━┛ │
│       ◉ PUSH      │ ← 赤いチャンスボタン＝再生
├───────────────────┤
│   バナー広告        │ ← いつも出す（広告を消すと消える）
└───────────────────┘
```

- 入力の決まり：**2行まで・1行6文字まで**。空のときは PUSH を押せない。書体にない文字は入力時に知らせる
- 待っている舞台の言葉は、入力に合わせて作り直す（打つたびではなく、入力を確定したとき）

### 流れ

1. 言葉を入れて PUSH → 入力欄とボタンが沈んで消え、舞台いっぱい（バナーの上まで）に演出
2. 終わると「もう一回」「書き出す」の2つが出る
3. 「書き出す」を押す
   - 広告を消していない人：ごほうび広告が流れる → 最後まで見たら書き出し開始。途中で閉じたら書き出さない（もう一度押せば見直せる）
   - ネットにつながっていない、または広告が読み込めないとき：「書き出す」は押せず、「ネットにつなぐと書き出せます」と出す
   - 広告を消した人：広告なし・ネットなしですぐ書き出し開始
4. 書き出し中は進み具合（％）を出す。終わったら「写真に保存」「共有」（LINE・X・TikTok などに送る iPhone の共有画面）

### 設定画面

- 火花：あり／なし（`SparksOn`）
- プチュンの光：色（青白・金・赤・虹）、大きさ（小・中・大）
- 書体：Reggae One／明朝（Zen Old Mincho Black）
- **昇格の範囲**：銀・金・虹の3枚のメダルを横に並べ、端から端まで指でなぞって「はじまりの色」と「おわりの色」を選ぶ（はじまり ≦ おわり）。6通り：銀だけ／銀→金／銀→虹（既定・いまの全部）／金だけ／金→虹／虹だけ
- 買い物：印を消す 300円／広告を消す 300円／セット 500円／購入を復元
- 設定は端末に保存し、再生にも書き出しにも同じように効く

## 2. 中の作り

### 演出の部品

すべての演出が同じ形を持つ。

```csharp
interface IPachiEffect
{
    void Build(string[] lines, float aspect, EffectSettings settings);  // 組み立てる
    float Duration { get; }                                             // 長さ（秒）
    void Evaluate(float t);                                             // 時刻 t の姿にする（状態を持たない）
    Camera Camera { get; }                                              // 描くカメラ
    void Dispose();                                                     // 片付ける
}
```

- いまの `PachiStage` を、この形の1つ目の部品「王道昇格」として包む。中身の流れは変えない
- 演出の一覧表（`EffectCatalog`）に、ID・名前・使うのに要る商品（第1弾はなし＝無料）を書く。2つ目は部品を1つ書いて1行足すだけで増える。配り方はアプリの更新に入れる
- `EffectSettings`：火花・光の色・光の大きさ・書体・昇格のはじまり・おわり。保存は PlayerPrefs

### 昇格の範囲

- ドンの着地は「はじまりの色」で落ちてくる。はじまりより下の昇格は飛ばし、「おわりの色」に着いたら余韻に入る
- 虹で着地したとき（虹だけ）は、着地のあとに回転（1回転→止まる→1回転）を入れる
- 時刻の並び（金になる時刻・切り裂く時刻・虹になる時刻・終わりの時刻）は、範囲から決める小さな関数に分け、自動テストで確かめる。長さの目安：銀だけ約9秒、銀→虹約15秒

### 再生

経過時間をそのまま `Evaluate` に渡す。終わりの時刻で止め、「もう一回」「書き出す」を出す。

### 書き出し

1. 画面に出さない 1080×1920 の描き先（RenderTexture）を用意する
2. 時刻を 1/30 秒ずつ進め、`Evaluate(t)` → カメラで描く
3. 印を出す人だけ、右下に「脳汁メーカー」の印を重ねる
4. 1コマずつ iPhone の動画づくりの仕組み（AVAssetWriter、H.264、30コマ/秒、無音）に渡す
5. mp4 ができたら、写真に保存（初回だけ許可を聞く。`NSPhotoLibraryAddUsageDescription`）か共有画面（UIActivityViewController）へ

- iPhone 側の部品は `Assets/Plugins/iOS/` に Objective-C で自前で書く（数十〜百行ほど）
- Windows の Unity では、iPhone 部品の代わりに PNG を並べる版が動き、作りの確認ができる
- 書き出し中に失敗したら（空き容量不足など）、何が起きたかと直し方を出して、作りかけのファイルを消す

### 広告

- AdMob（ほかのアプリと同じアカウント、Google の無料の Unity 用部品）
- 下のバナー（画面幅に合う大きさ）と、書き出し前のごほうび広告
- 組み立て中はテスト広告、ストアに出す版だけ本物（天落杯と同じ切り替え方）
- 広告の追跡の許可（ATT）を初回に聞く。app-ads.txt は maosun-dev.com に置いてあるものを使う

### 課金

- Unity の無料の課金部品（Unity IAP）。3つとも買い切り（非消耗型）

| 商品 | 値段 | 効くこと |
|---|---|---|
| 印を消す | 300円 | 動画の印が消える |
| 広告を消す | 300円 | バナーと書き出し前の広告が消え、ネットなしでも書き出せる |
| セット | 500円 | 上の2つとも |

- セットは、どちらも買っていない人にだけ見せる。片方を買った人には残り1つ（300円）だけを見せる
- 「買ったもの」から「印を出すか」「広告を出すか」「セットを見せるか」を決める部分（`Entitlements`）は、ほかから切り離して自動テストで確かめる
- 「購入を復元」で、機種変更した人も取り戻せる

## 3. 組み立てと配信

- GitHub に `maosun-dev/pachieffect` を**公開**で作る（ほかのアプリと同じ。公開なら組み立てが無料で使い放題）。ストアに出したら非公開にし、更新を組み立てるときだけ公開に戻す（ユーザーの方針。一度公開した間に写されたものは消せないことは承知のうえ）
- 組み立ては2段
  1. GitHub の Linux 機で、GameCI（無料の道具）を使って Unity が iPhone 用の Xcode の作りを作る
  2. GitHub の Mac で Xcode が仕上げ、TestFlight に送る（天落杯と同じ App Store Connect の鍵の形）
- 手元の Windows に iOS 用の部品は入れない
- 秘密（GitHub の Secrets）：Unity のアカウント情報・ライセンス、App Store Connect の鍵、チーム ID。**入力はユーザーがやる**
- ユーザーにやってもらうこと：上の秘密の入力、App Store Connect でアプリと課金3つの登録、AdMob でアプリと広告枠（バナー・ごほうび）の作成

## 作る順番

1つずつ作業計画（writing-plans）を立てて進める。

1. **組み立ての道を先に通す**：今の演出をそのまま再生するだけのアプリを TestFlight に届ける（いちばん詰まりやすいところを最初に片付ける）
2. 演出の部品化と設定（昇格の範囲を含む）、メイン画面、設定画面
3. 動画の書き出し、印、写真に保存、共有
4. 広告（バナー・ごほうび）、課金3つ、購入の復元
5. ストアに出す準備：アイコン、画面写真、プライバシーポリシー（maosun-dev.com に置く）、審査に出す（提出はユーザーに確認してから）

## 確かめ方

- 自動テスト（Unity の EditMode テスト）：買ったかどうかの判定、入力の決まり（2行・6文字）、昇格の範囲から時刻の並びを作る部分、設定の保存と読み込み
- 見た目：今までどおり書き出した絵（capture.sh・movie.sh）で確かめる。昇格の範囲6通りをそれぞれ書き出して見る
- iPhone での動き（再生の滑らかさ、書き出し、保存・共有、広告、課金）：TestFlight でユーザーに見てもらう。課金は Apple のテスト用の環境（サンドボックス）で試す

## 気をつけること

- Unity の個人向けライセンスを GitHub の組み立て機で使う手順は、GameCI の説明どおりに行う。うまく通らないときは、順番1で止めて相談する
- 書き出しの速さは端末しだい。古い iPhone で遅すぎるときは、解像度を 720×1280 に下げる道を残す
- 書体にない文字（絵文字など）は入力の時点で知らせる
